# M8 Connect — Frontend

React + Vite. Consume la API en `http://localhost:8000` (proxy en `vite.config.js`).

## Desarrollo

```bash
npm install
npm run dev
```

## Rutas principales

| Ruta | Pantalla |
|------|----------|
| `/login` | Login |
| `/upload` | Landing (Historia / Catálogos) |
| `/upload/history` | Wizard historia |
| `/upload/catalog` | Wizard catálogos |
| `/catalogs` | Admin catálogos |
| `/batches` | Listado batches |

Ver [`../docs/FUNCIONAMIENTO_APLICACION.md`](../docs/FUNCIONAMIENTO_APLICACION.md).
